# Quantum QDS Threat Detection - Frontend Web Dashboard

Modern React + TypeScript + Vite + Tailwind CSS dashboard for visualizing teleportation-based Quantum Digital Signatures (QDS) and deterministic cyber threat telemetry.

---

## Features
- **Live Health & Telemetry**: Dynamic polling of backend status, database connection, and subsystem readiness.
- **Architectural Status**: Real-time readiness overview of the 5 core threat vectors and quantum simulation engines.
- **High-Tech Aesthetic**: Dark mode UI inspired by quantum computing & cyber defence operations centers.

---

## Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Configure Environment
```bash
cp .env.example .env
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 4. Build for Production
```bash
npm run build
```
